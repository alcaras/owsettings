Set up your lobby without launching the game

Pick a tournament map (or an FFA), choose which lobbies to update, point this page at your GameOptionsSave.xml, and it rewrites just the tournament settings — everything else in your file stays exactly as it was.

Your file is processed on this device only. Nothing is uploaded — this page cannot make network requests.
Quit Old World first. The game rewrites this file when it closes, so anything you change while it's running is lost.
Back up your settings file. The folder flow below writes a dated backup next to the original automatically; if you use the download flow, keep the original file somewhere safe before replacing it.
