# CLAUDE.md — agent guide for owsettings

Browser-only tool that rewrites a player's Old World `GameOptionsSave.xml`
to the community-tournament ruleset (duel pool map or FFA). Static site on
GitHub Pages, styled after `owreference`. **Live:** https://alcaras.github.io/owsettings/

- **Git identity:** commit/push as `alcaras <alcaras@subcreation.net>` (never the personal identity).
- **Never commit a real `GameOptionsSave.xml`** — it holds the player's name and email. `.gitignore` blocks it; `test/fixtures/*.xml` are scrubbed copies (Windows CRLF + Mac LF).

## Layout

```
index.html / style.css / app.js   the page (no build step; CSP: connect-src 'none')
xml.js        tiny parser + .NET-XmlSerializer-shaped serializer (BOM, CRLF/LF, ` />`, no trailing newline)
apply.js      the preset: MANAGED keys per lobby section; everything else passes through
labels.js     en-US labels for the ids we touch (from Reference/XML/Infos/text-*.xml)
presets.js    GENERATED by scripts/build_presets.py — 18 duel maps + 21 FFA scripts
scripts/build_presets.py   imports ../owmapgen-lab/scripts/{configs,ffa_configs}.py; POOL slugs mirror
                           owtournamentatlas/src/pages/index.astro; MAP_CLASS table = MAPCLASS_ + C# class name
test/*.test.mjs            node --test; round-trip byte-identity is the load-bearing test
img/maps/<script>.png      FFA thumbnails from owreference/public/img/mapscripts/<script>-1.png
img/maps/duel/<slug>.png   duel cards: exact-config previews from owtournamentatlas/public/img/atlas/<slug>/seed-1.png
```

## Rules that took work to settle (don't relitigate)

1. **Respect their file.** Only the managed set in `apply.js` changes. Unknown/stale ids
   (e.g. `GAMEOPTION_NO_BAD_COGNOMENS`, `NO_GRAND_VIZIERS` — gone from the game) and
   settings the ruleset doesn't name (gifting flags, resource density, difficulty,
   `defaultSimultaneousTurns`, connected starts) pass through untouched.
2. **Per-lobby diffs:** Network = crits hidden (`GAMEOPTION_CRITICAL_HIT_PREVIEW` off),
   Tight + Slow timer, observers on. Cloud/Hotseat = crits shown, Strict, no timer.
   Undo allowed everywhere (`GAMEOPTION_NO_UNDO` absent) so a network → cloud conversion keeps it.
3. **Ruins:** duel = `GAMEOPTION_NO_BONUS_IMPROVEMENTS` on; FFA = off. That id *is* "No Ancient Ruins".
4. **Calamities = `OCCURRENCELEVEL_CALAMITIES_VERY_LOW`** ("Very Rare") — from the organiser's
   file; the rules doc says "Rare" (`_LOW`). Organiser confirmed Very Rare 2026-09-02.
5. **Seats:** first N seats normalised (nation NONE = Pick Later, team i, dynasty DEFAULT,
   archetype PICK_LATER, human). Arrays are padded, never truncated. Difficulty untouched.
6. **Network also forces `GAMEOPTION_ALLOW_OBSERVE` on.** Every chosen lobby empties
   `defaultDisabledContent` (all DLC on) and `PlayerOptions/useModsInMultiPlayer` is set false
   (the SP `modSelections` list is untouched).
7. Map class ids are case-exact C# names (`MapscriptMountainPass`, `MapScriptInlandSea2`…);
   `VICTORYPOINT_MEDIUM_HIGH` displays as "High"; Archipelago `WATER_SIZE_MERGED` displays as "Small".
8. **Fixture identity test** (`test/xml.test.mjs`) must stay byte-for-byte on both fixtures. If the
   game changes its serializer shape, fix `xml.js`, don't loosen the test.

## Updating the pool

Edit `POOL` in `scripts/build_presets.py` (keep in sync with the atlas `index.astro`), run
`python3 scripts/build_presets.py`, `npm test`, commit `presets.js`. New scripts need a
`MAP_CLASS` entry + a thumbnail in `img/maps/`.
